## About

Computer engineer and frontend developer based in Ankara, building for the web since 2021.

I work on the Enterprise Growth team at [Jotform](https://www.jotform.com/), where I joined as an intern in 2024 and grew into a full-time role. My work is A/B testing, conversion rates and lead generation: landing pages built from Figma and shipped through CI/CD, plus faster, better forms.

Before that, I was the sole web developer at [Pepteam](https://www.pepteam.net), a 6-person startup, where I built the admin dashboard, the super admin panel and the content site for the Parently app. I also led the web team at GDSC Kırıkkale. I graduated from Kırıkkale University with a B.Sc. in Computer Engineering.
